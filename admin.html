Edit the moving sale

Sign in with a GitHub access token to change prices, mark things sold and add photos.

How do I get a token?
  1. Go to GitHub → fine-grained tokens → Generate new token.
  2. Give it any name, e.g. moving sale, and an expiry (a year is fine).
  3. Under Repository access pick Only select repositories → this site's repo.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate it, copy the token, and paste it above. It is stored only in this browser and sent only to github.com.
